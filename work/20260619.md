# 2026년 06월 19일 작업 내역 (Otalk App)

## 1. 초기 웹 앱 기반 설정 및 기획
- Firebase Hosting 연동 (`otalk-app.web.app` 배포)
- Firestore Database 및 Authentication 연동 (구글 로그인 기반)
- GmarketSansTTFBold 폰트 전역 적용
- 블랙/골드(앰버) 기반의 고급스러운 다크 모드 UI/UX 설계 및 적용 완료

## 2. 권한 및 롤(Role) 시스템 구현
- Firebase Firestore를 활용한 AppUser 모델 생성 (`super_admin`, `admin`, `user` 권한 분리)
- 마스터(최고 관리자) 권한 양도 기능 및 일반 관리자 권한 부여 기능 구현
- 권한 관리 화면(`admin_users_screen.dart`)에서 관리자와 일반 사용자 리스트업 및 강등/승급 기능 구현
- 일반 관리자의 명칭을 '관리자'로 통일

## 3. 멤버(Member) 관리 시스템
- 회원의 닉네임, 출생년도, 지역, 성별, 가입일, 총 참석 횟수 및 총 지출 금액 통계 제공
- 검색 기능 탑재 (초성 검색 및 닉네임 검색 지원)
- 모바일 환경에서의 테이블 레이아웃 최적화 (가로폭 조정, 불필요한 텍스트 제거)

## 4. 모임(Meeting) 게시판 및 정산 시스템
- 모임 생성 시 차수(1차, 2차 등)별 총 비용, 장소, 입금 계좌 입력 기능 제공
- 각 차수별 참석자를 등록하고 수정할 수 있는 UI 제공 (멤버 추가 다이얼로그)
- **접근 권한 처리**: 일반 사용자는 기존 멤버만 검색/추가할 수 있으며, '신규 멤버 직접 등록'은 관리자만 가능하도록 제한
- **삭제 및 권한 제어**: 모임 작성자 본인 또는 관리자 권한을 가진 사용자만 삭제 가능
- **Soft Delete(이력 보존)**: 삭제 시 DB에서 데이터를 완전히 지우지 않고 `status: 'deleted'` 값을 주어 화면 목록 및 통계에서 제외 (이력 추적 용이)

## 5. 대시보드(Dashboard) 및 통계
- 오늘 생일자 리스트 표시
- 이번 달 참석 왕(가장 많이 참석한 멤버) TOP 10 표시
- UI 공간 절약을 위해 스크롤 방지 및 높이 최적화 완료

## 6. 기타 수정 사항
- 프로필 위젯 클릭 시 로그아웃 등 액션 처리
- 좁은 해상도에서 멤버 선택이나 리스트 뷰가 잘리는 문제(Overflow) 해결
- 권한 변경 시 화면 상에 즉각 반영되도록 StreamBuilder 구조 도입
